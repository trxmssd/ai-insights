今日摘要
主权算力正从规划文件变成开工现场。韩国国家 AI 计算中心 8 月 3 日在全罗南道海南动工，目标 2028 年建成 1.5 万张先进 GPU 规模的算力底座，由三星 SDS 联合体承建，并在同一园区设研发区，为国产 AI 芯片提供验证与商用支持；同日 Rebellions 中标国产 NPU 公共 AI 项目。亚太重心仍在承接侧：马来西亚数据中心投资已达经济总量近两成，为全球最高；Colt 与 RMZ 拟在印度建 1.25GW 园区。
今日最重要的三项变化
1. 马来西亚 AI 数据中心投资占经济总量近两成，柔佛与槟城分工定型
为什么重要：一国把接近两成的经济总量押在单一基建门类上，说明 AI 算力已不是产业政策里的一个条目，而是增长模型本身；电力、土地与人才约束会直接反映到国家层面的宏观数据上。
对亚太 / ICT 的影响：面向马来西亚的方案竞争重心正从建设速度转向长期效益论证，本地增值与用电效率进入评审口径；柔佛承接算力、槟城承接芯片，两条线的客户画像与交付节奏需要分别设计。
2. 阿里发布 2.4 万亿参数 AI 基座模型 Qwen3.8，AI Agent 千问办公同日公测
为什么重要：基座模型与办公 Agent 同日推出，把模型能力与可交付的工作流绑进一次发布；OSWorld-Verified 这类操作系统级任务基准居首，比语言基准更接近 Agent 的真实作业。
对亚太 / ICT 的影响：亚太客户的 AI Agent 选型可选集，从模型 API 加自建编排扩展到模型加现成办公 Agent；开源版若如期放出，本地部署与私有化交付会再增一套可行方案。
3. 韩国国家 AI 计算中心开工，同场为国产 AI 芯片提供验证与商用支持
为什么重要：把算力供给与国产芯片验证放进同一园区，等于用公共算力订单给本土芯片生态做首批场景；这是主权 AI 从采购清单走向工程范围的分界点。
对亚太 / ICT 的影响：亚太多国正在筹备同类项目，韩国的组织形式提供了直接可比的模板：官民合资公司承建、过渡期先借用商业数据中心算力、研发区与生产区同址。

重点事件分析
马来西亚把 AI 数据中心投资推到经济总量近两成，审批口径转向长期效益
事件事实
据 The Edge Malaysia 引述彭博与汇丰分析师测算，马来西亚数据中心投资已达其经济总量近两成，为全球最高水平；2021 年至 2025 年上半年获批数据中心投资 1444 亿林吉特。第二季经济同比增长 5.8%，高于 5.2% 预期，摩根大通随后上调 2026 年增速预测至 5.3%。柔佛承接数据中心开发商，槟城承接芯片资本，今年电子电气产品出口预计超过 8000 亿林吉特。金务大 6 月称订单簿因数据中心项目创 520 亿林吉特新高。IMF 数据将马来西亚列为全球四大 AI 相关硬件净出口地之一。
为什么重要
一国把接近两成的经济总量押在单一基建门类上，说明 AI 算力已不再是产业政策里的一个条目，而是增长模型本身。这也意味着电力、水、土地与人才的约束会直接反映在国家层面的宏观数据上，而不只是停留在项目进度表里；宏观增速与单一门类投资的绑定越紧，政策端对项目质量的挑剔程度就越高。
亚太及 ICT 影响
面向马来西亚的方案竞争重心正从建设速度转向长期效益证明——本地增值、用电效率与人才留存会陆续进入评审口径，投标材料需要提前准备可核验的量化承诺。柔佛与槟城的分工定型，意味着算力交付与芯片制造两条线的客户画像、交付节奏与合作方选择需要分别设计，用同一套打法覆盖两地已经不成立。
后续观察点
1. 汇丰口径的数据中心投资占经济总量比重在下半年是否继续上升
2. 柔佛新增项目的并网时序与电价条款是否出现新的限制
3. 槟城芯片资本与柔佛算力之间能否形成本地供货关系
4. 森美兰州选结果对数据中心审批节奏与政策连续性的实际影响
阿里 Qwen3.8 与 AI Agent 千问办公同日推出，定价直指规模化调用
事件事实
8 月 3 日阿里发布基座大模型 Qwen3.8，采用稀疏 MoE 与混合注意力联合优化，总参数 2.4 万亿、激活 950 亿，上下文 100 万 Tokens，支持视觉理解。IF Bench 82.8 分、GPQA Diamond 92.6 分、OSWorld-Verified 86.1 分居主流模型首位，CodeArena 全球第四。API 已上线千问 AI 平台，国内每百万 Tokens 输入 12 元、输出 36 元，缓存命中 1.5 元。AI Agent 产品千问办公同日公测。Qwen3.8-Max 与 Qwen3.8-27B 预计下周开源，阿里真武 M890 超节点已完成适配，Agentic 推理最多提升 1.5 倍。
为什么重要
基座模型与办公 Agent 同日发布，把模型能力与可交付的工作流绑成一次发布。OSWorld-Verified 这类操作系统级任务基准居首，比语言类基准更接近 Agent 的真实作业；配合缓存命中价，指向的是高频、长上下文的规模化调用场景，而不是演示性质的试用。
亚太及 ICT 影响
亚太客户在做 AI Agent 选型时，可选集从模型 API 加自建编排，扩展到模型加现成办公 Agent。开源版本若如期放出，本地部署与私有化交付的可行方案会再增一套。超节点适配同时说明，模型与国产算力的协同优化正在成为发布的常规内容，方案侧需要准备多套算力底座的适配能力，而不是绑定单一硬件路线。
后续观察点
1. Qwen3.8-Max 与 27B 开源版本的许可证条款与商用边界
2. 千问办公在亚太多语种与合规场景下的实际可用性
3. 缓存命中定价对长上下文任务总成本结构的实际影响
4. 真武 M890 超节点之外，官方公布的算力适配清单范围
 
业务启示
今日三个产业判断
1. 主权 AI 算力从预算科目变成开工现场，国产芯片验证被写进同一份工程范围。韩国把算力供给与国产 NPU 验证放在一个园区，Rebellions 同日拿到公共部门订单，说明买算力与养芯片正在被当作一件事来做。
2. AI 基座模型的竞争点从参数规模转向可交付的作业能力。DeepSeek V4-Flash 只改后训练就把智能体能力拉到顶尖水平，阿里把办公 Agent 与基座模型同日发布，两者指向同一件事：能不能干活比有多大更要紧。
3. 存储与先进封装的紧缺正在改写整机成本结构。Omdia 把 2026 年半导体收入增速上调至 94.1% 并预计存储占比过半，铠侠用 SSD 去补 HBM 的容量缺口，是同一个瓶颈的两个侧面。
对亚太 ICT 的三个启示
1. 面向东南亚与澳新的算力项目，供电方案与长期效益论证要前置到方案阶段。马来西亚已把审批第一标准转向长期经济效益，1414 Degrees 的南澳项目直接把并网点、储能与分期扩容写进意向书。
2. AI Agent 的行业落地正从概念转入受约束的生产部署。菲律宾群岛银行把 agentic AI 用在车贷审批并限定复制路径，HashMicro 用 Model Context Protocol 打通 ERP，共同点都是先划边界再放权。
3. 网络侧的机会随算力布点同步放大。Ciena 测算东南亚高容量连接需求年增 22%、高于全球的 18%，园区之间与园区到用户的连接需求正在成为独立商机，而不只是数据中心的配套项。
建议继续跟踪的五个问题
1. 韩国国家 AI 计算中心 2027 年过渡算力的实际交付方式与定价机制
2. Qwen3.8 开源版本的许可证条款及其对亚太私有化部署的影响
3. 马来西亚审批口径转向长期效益后，在审数据中心项目的通过率变化
4. 铠侠 GP1 与英伟达 Storage-Next 的实际落地案例与容量分层比例
5. 欧盟通用 AI 模型执法权启动后，首批被要求做上市前评估的模型清单
