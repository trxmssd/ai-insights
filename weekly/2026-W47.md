### 信号 1｜推理 Token 变成按单位计价、可跨境交付的商品：一周内卖方把单价压到每百万 0.5 元、对手价的 5%，同一周头部免费入口被挤到限流——「买 Token」开始和「建机房」直接比价

**事实**

- **11-16 日报**：11-13 全国首个昇腾 950DT「Token 出口」算力集群在中国电信汕头国际海缆登陆站点亮，单卡 FP8 1P、FP4 2P、144GB 显存；广东天亿马一号 Token 工厂一期投资约 **10 亿元**、配套 **2000P** 专用算力，文中称日均 Token 调用半年内由 1 亿次增至 1000 亿次，已登记海外需求超 **3 万亿次每日**（登记需求，非实际消耗），二号工厂已签约。同日新华社稿称全国日均推理 Token 调用约 **500 万亿次**；**11-20 日报**给出同一口径的时间线：从 2024 年初约 1000 亿增至 2026 年 7 月约 500 万亿，全国智能算力 9 月末 **2592 EFLOPS**、同比增 146%。
- **11-18 日报**：腾讯混元 Hy4 flash（总参数 224B、激活 12B）在 TokenHub 定价输入 **0.5 元**每百万 Token、输出 2 元、缓存命中 0.02 元，11-04 发布的 Hy4 是输入 6 元、输出 18 元，内部办公基准单任务成本降至二十分之一（公司自测）；微软 MAI Code 2 自述达 Claude Opus 5.5 约 96% 质量而价格为其 **5%**、达 GPT-6.1 Sol 约 98% 质量而价格约 40%；Sarvam Token Factory 自研 105B 模型促销价每百万 Token 输入 10 卢比、输出 25 卢比，七款开源权重模型全部跑在印度境内 GPU；LG U+ 称模型路由与异构算力最高可省约九成任务成本（**11-16 日报**的内部验证口径为 Token 成本降约 25%、质量保留约 95%）。**11-15 日报**：百度「词元所」试运营上架 40 多个模型、日均接口调用超 5000 万次，发布首日新增客户接入超 1000 家（百度口径）。**11-14 日报**：DeepSeek 开放应用级 API，扩展能力在词元费之外另收工具调用费，单价未公布。
- **11-17 日报**（据报道）：DeepSeek 自 11 月中旬对 App 与网页版免费用户限额——单次输入上限降至约 4 万字、新增每日额度，部分用户不足 2 小时即被限流，开发者 API 不受影响；背景是 V4.1 Flash 在 10-19 至 10-25 单周 Token 调用 **33.6 万亿**、环比增 **801%**，近一个月官方状态页记录 8 起服务异常。**11-19 日报**：限额两日未松动，C 端是否转付费尚无规则。同日 MangoBoost 与 PFN 签备忘录验证「GPU 做 prefill、MN-Core 做 decode」的 Token Factory 架构。**11-20 日报**：Sarvam 平台 12 个模型中 6 个来自中国开发者，入门价每百万输入 14 卢比、输出 55 卢比。

**判断**

W45 看到词元调用量领先与自托管降本九成；本周 Token 同时凑齐了商品的三件套。有货：汕头把推理集群放在海缆登陆站，卖的是跨境交付的 Token，不是机房和机柜。有价：腾讯、微软、Sarvam 在同一周公开每百万 Token 标价，腾讯一次把输入价从 6 元砍到 0.5 元，降价不是促销而是换代。有交易场所：百度词元所、腾讯 TokenHub、Sarvam Token Factory 三个平台同时把多家模型放进一个计价口径里比。但需求比供给跑得快——DeepSeek 单周调用环比涨 801% 之后只能对免费用户限流，说明降价只对付费 API 成立，免费入口靠补贴撑不住峰值。推理市场因此在分层：付费 API 降价抢量、按峰值保障收费，免费 C 端限额。对亚太的含义是，「买 Token 不买机房」第一次成了有公开报价可比的选项，任何自建推理方案都要回答一个问题：折算到每百万 Token，比 0.5 元、比 10 卢比贵多少，贵在哪。

**启示**

华为亚太的算力与 AI 云方案把「每百万 Token 综合成本」做成报价首页的固定口径：把自建推理折算成每百万 Token 的电费、折旧、运维三项，与汕头、TokenHub、Sarvam 的公开价并列，差价必须落到数据不出境、时延、峰值不限流这三个可验证的理由上，讲不出理由的差价客户会直接拿去压价。对运营商客户推「海缆登陆站 + 推理集群 + Token 批发」的组合：运营商手里有登陆站、有跨境带宽、有计费系统，汕头已经证明这三样能拼成一门 Token 出口生意，亚太的新加坡、香港、马来西亚登陆站都可以照这个模式算账。报价按「词元 + 工具调用」两段写，不再沿用单一词元口径——DeepSeek 工具调用费未定价，就给区间假设并写明依据。峰值保障单列成可收费的服务等级：DeepSeek 限流这一周就是最好的销售材料，企业客户要的是高峰时段不被挤掉。

### 信号 2｜AI 数据中心的准入第一次被写成价格和时钟：社区惠益按兆瓦收费、审批按用电分七级、审批由串联改并联——同一周澳、泰、印尼都有项目被暂停、叫停或停工

**事实**

- **11-14 日报**：泰国内阁 11-10 通过按用电量划分七级的数据中心监管框架，0.5MW 及以上纳入监管、20MW 及以上须进工业园区，110 余家申请方电力需求叠加逾 **30000MW**，官方估计仅约**四分之一**为真实投资者。澳大利亚 Quantum DC 暂停阿德莱德以东 Tungkillo **1200MW** 项目审批，逾 350 名居民联系公司并提交 **432 个**集中问题（水、电、噪音、暗夜光污染、交通、山火、农地），CEO 称误判了社区反对强度；同日 AirTrunk 为新州园区锁定超 1GW 风光储资源，但仅为独家推进协议、长期购电协议未签。
- **11-15 日报**：塔斯马尼亚州对 20MW 以上项目要求按合同确定性负荷每兆瓦每年至少 **3000 澳元**进入社区惠益基金，随通胀指数化、覆盖全生命周期、易主后继续有效，100MW 项目每年至少 30 万澳元，并要求开发商自付并网与电网升级费用、季度报送能耗水耗（以政府与企业协议执行、无罚则，六个月后复审）。马来西亚数字部答复国会：《数字基础设施（数据中心）法案》计划 **2027 年**提交，数据中心列为支撑 AI 的关键基础设施。沙巴州首座 AI 数据中心签备忘录，州政府明言「签备忘录不等于批准」，列出电力与水供、冷却技术、环保、土地等前置评估。
- **11-17 日报**：泰国 2026 年 9 月叫停 **49 个**项目、暂缓 **117 个**项目审批；印尼西爪哇 Jatiluhur 的 BDX 数据中心因缺环评与建筑许可被叫停，巴淡岛 Nongsa 居民因数月净水短缺抗议；Wood Mackenzie 估算数据中心已占柔佛用电 **24%**、2035 年或达 40%。同日香港沙岭数据园区全面动工，政府组建 16 个部门专责小组，在不改法规前提下审批由串联改并联，首期由原定 2029 年提前至 **2027 年中**。
- **11-18 日报**：马来西亚前九个月数据中心与云计算获批投资 **1235 亿林吉特**、同比增 44.5%，占全国获批投资比重升至 35.2%，新项目设 **30%** 最低本地含量门槛；马银行判断审批将在电力与水资源上趋严、获批集中于美国主要超大规模云厂商；泰国总理与 AWS 商讨扩建并拟设一站式审批窗口。**11-19 日报**：Equinix 菲律宾称最大瓶颈是电力可得性与并网时间表，单纯加算力不够。

**判断**

W45 看到审批方把电力合约写成并网要件、发电商主动要求筛人；本周的新变化是准入第一次有了单价和时钟。单价：塔州把社区成本写成每兆瓦每年 3000 澳元、随通胀走、跟着资产转让，这不是一次性的公关支出，而是一笔随资产走的长期负债，可以直接进财务模型。时钟：泰国按用电量分七级、叫停 49 个、暂缓 117 个，等于告诉申报方大部分申请会被筛掉；香港把审批由串联改并联，首期提前约一年半，把审批速度本身做成了招商卖点。两件事合在一起，准入不再是批或不批的二元题，而是「准入成本 × 等待时间」的函数，项目方比的是谁先拿到确定性。马来西亚获批额同比增 44.5% 和马银行「审批转严、集中于美国头部云」同时成立，说明批得多但批给谁在收窄——中型客户和新进入者会是第一批被挡在门外的。Quantum DC 的 432 个问题说明，社会许可没法像电力那样提前六年锁定，它只能在选址期同步做。

**启示**

华为亚太数据中心方案在首页加一张「准入成本与时间表」：按市场列出社区成本（塔州每兆瓦每年 3000 澳元起）、审批分级档位（泰国七级、20MW 进园区）、本地含量门槛（马来西亚 30%）、典型审批时长与最近一次规则变化日期，客户询单当天就能拿出。面向非头部云的中型客户与主权 AI 项目，把「审批确定性」做成单独的服务包：环评、供水、并网、社区沟通四条线在选址阶段同步启动，各自给出负责人与时间点——马银行已经点明审批会向头部云集中，中型客户最缺的就是这一块。把香港沙岭 2027 年中首期、泰国一站式审批窗口、马来西亚 2027 年法案提交这三个时点写进 2027 年亚太数据中心的商机日历，它们是能提前排的询单节点。报价里社区成本与审批周期一律给区间不给单点：塔州框架六个月后复审，泰国细则未出，用单点报价等于替客户承担规则变化的风险。

### 信号 3｜AI 产能被头部买家用「专属产能 + 预付款」整段锁走：载板、封装、光模块、存储、备用电源的排单都指向 2027—2028 年，代价开始从非 AI 品类和中间环节的毛利里扣

**事实**

- **11-18 日报**：英伟达宣布扩大对台积电、鸿海、景硕、矽品、Amkor 与三星电机六家伙伴的承诺：景硕在桃园青埔扩建 ABF 载板**专属产能**，2027 年下半年投产、2028 年第三季较现有提升 **3.5 倍**以上；矽品获数十亿美元级资金扩建台湾先进封装，专属产能至 2029 年中前提升；Amkor 7 月与 10 月的多年期协议合计近 **30 亿美元**并含预付款。**11-16 日报**：因 CoWoS 产能不足，英伟达把 CoWoS 后段基板封装分流给矽品与 Amkor，矽品计划 2027 年中把 CPO 产能拉到现在的 **15 倍**以上。**11-20 日报**：矽品宣布与英伟达签数十亿美元长期协议（金额未披露）。
- **11-19 日报**：腾讯三季度资本开支 814.3 亿元、环比增 54%，另含约 **860 亿元**算力预付款，自由现金流为负 **691 亿元**，净现金转为净负债 137 亿元。光模块三家同日公告：中际旭创董事长提议回购 20 亿至 40 亿元，胜宏科技称部分高端产品排单延至 **2028 年**；**11-17 日报**：中际旭创称 2027 年订单已基本覆盖、部分核心客户给出 2028 年需求指引。同日央视财经调研：数据中心柴油发电机组 2026 年国内需求预计破 6000 台，玉柴大功率机组订单排到 2027 年 10 月、上游曲轴订单排到 2028 年。
- **11-17 日报**：三星 DX 部门 2026 年前九个月移动存储采购均价较 2025 年全年上涨 **263%**，外购移动存储支出 7.6993 万亿韩元；中芯国际产能利用率 97.3%，管理层称 AI 配套芯片拉货快于预期，而手机、低端网通与 IoT 致存量需求双位数下滑。**11-18 日报**：长鑫科技三季度营收 1187.14 亿元、同比增 613.18%，DDR5 紧缺预计贯穿四季度；部分 IC 设计公司已收到 2027 年晶圆报价调升 **10% 至 20%** 以上的通知（据报道），世芯 10 月营收同比增 515.81% 但三季度毛利率降至 **18.04%**、为近三年最低，创意由 24.2% 降至 20.6%。**11-20 日报**：阿里 CEO 吴泳铭判断 2027 年和 2028 年将是中国算力最紧缺的两年。

**判断**

W45 看到存储、光模块、封装的 2027 年产能被「预订完」；本周看到的是锁法变了。以前是买方下长约、卖方排产；现在是买方直接出钱给供应商建只给自己用的产能，并先付款。景硕 3.5 倍的增量、矽品扩出来的先进封装、Amkor 含预付的 30 亿美元，名义上是供应商扩产，实际上是英伟达把 2027—2029 年的增量从公开市场里划走了。腾讯单季 860 亿元预付款超过当季 814.3 亿元的资本开支，说明国内头部买家也在用同一招，代价是自由现金流转负。产能被整段锁走之后，成本往两头挤：一头是非 AI 品类，三星给自家手机买存储要多付 263%，中芯国际的手机与 IoT 需求双位数下滑；另一头是中间环节，晶圆涨价 10% 到 20% 转嫁不出去，ASIC 设计服务商营收涨五倍、毛利率却跌到三年最低。不在专属名单里的买家，2027 年拿到的是剩下的产能和更差的交期。

**启示**

华为亚太给运营商与政企客户的 2027 年 AI 交付计划，一律按「非专属产能」的交期做备案：载板、先进封装、高速光模块、服务器内存、大功率柴发五类物料单独列出可得时点与替代方案，签约阶段就锁定，不要等到实施阶段再下单——柴发曲轴已经排到 2028 年，这是数据中心项目里最容易被忽略的一项。对自身关键物料，用多年期框架协议加分期预付锁定份额，学英伟达的做法而不是按季询价。终端、IoT 与传统网络类方案的报价提前计入存储与成熟制程涨价：三星内部采购都涨了 263%，亚太客户的手机与 IoT 项目成本假设如果还按去年，毛利会被吃掉。对客户讲清「2027、2028 是最紧的两年」这个判断，帮他们把扩容节点前移或分期，是现在最有价值的咨询内容。

### 信号 4｜AI 资金在分层：模型头部在股权市场拿到美股史上最大一笔钱，承接算力的新型 AI 云债务成本走到两位数、供应商兜底开始收

### 信号 5｜AI Agent 的监管和商业化在同一周落到「支付权限」上：监管划沙盒、建代理身份协议，发卡组织搭通道，银行先把损失划给用户——谁能核验代理身份，谁就拿到 Agent 交易的入口

**判断**

W45 看到 AI Agent 变成持证方的合规义务，香港金管局发出「认识你的代理人」咨询；本周这件事从咨询走到了要建的统一协议，而且商业侧同步把 Agent 的闭环押在了支付上。监管关心的对象换了：不是模型说了什么，而是代理能动用多少钱、多快动用——新加坡金管局担心的是存款被代理按微小收益来回搬，这是流动性问题，不是内容问题。商业侧，NAVER 把广告从按点击改成按成交，意味着 Agent 的收入直接挂在交易上。在代理身份协议落地之前，银行的第一反应是免责：第三方 Agent 出事用户自担，这会把交易往平台和银行自有代理那里赶。Kakao 给出的 800 韩元对 5 韩元说明，走协议直连比让 Agent 模拟浏览器点按钮便宜两个数量级——代理身份核验加 API 直连会成为一层新的基础设施，而且是有监管背书的那一层。

**启示**

华为亚太面向银行、支付机构与运营商的 Agent 方案，把「代理身份核验 + 权限与限额 + 全程审计日志」做成标配模块而不是可选项，模块的字段直接对齐新加坡金管局沙盒的授权与限额要求，以及即将出台的代理身份协议，先在新加坡、香港做概念验证，拿监管沙盒的结论去其他东盟市场复制。对运营商客户提出明确主张：运营商手里有实名号码、SIM 身份与计费结算能力，天然适合做 Agent 的身份锚点与小额支付承载方，这比和互联网平台拼模型更有胜算，现在是窗口期。方案里默认走 MCP 与 A2A 这类协议直连而不是浏览器自动化，把单次调用成本差两个数量级的账算给客户看。

## 三、本周一个数字

# 860 亿元

腾讯三季度在 814.3 亿元资本开支之外，另付约 **860 亿元**算力预付款，单季自由现金流因此为负 **691 亿元**，净现金转为净负债 137 亿元，而同季归母净利只增 0.8%（**11-19 日报**）。

这个数字的分量在于：预付款比当季全部资本开支还多。它说明头部买家已经不满足于下长约，而是先把钱付出去换产能确定性——和英伟达给景硕、矽品、Amkor 出资建专属产能是同一个动作（信号 3）。买方愿意为确定性把现金流打成负数，卖方的订单能见度因此拉到 2028 年，夹在中间的是没能力预付的二线买家和新型 AI 云，它们的债务成本已经到两位数（信号 4）。

对我们的含义是：2027 年的 AI 项目，谁能帮客户提前锁住物料、谁能接受与客户现金流对齐的付款节奏，谁就拿到订单。交付能力和付款条件，比单价更重要。
